# 衡练 · SportHealthAgent

基于 HarmonyOS NEXT（ArkTS / ArkUI）的端侧运动健康 Agent：录入运动与力量训练数据后，由**本地确定性规则引擎**即时输出训练评估、饮食方案与互补训练规划，全程不联网、无云端模型调用。

## 核心特性

- **端侧规则引擎**：训练评估（负荷三档 + 恢复时长）、饮食方案（宏量配比 + 热量）、互补训练规划三大模块，参数集中可配（`RuleConfig`）
- **力量训练闭环**：训练日志（组数×次数×重量×RPE/RIR）、1RM 双公式估算、渐进超负荷建议、热身组生成、个人纪录（PR）追踪与按天聚合
- **发现页**：训练历史月日历（周一开头、翻月、当日明细与当日 PR）、周/月/年数据统计（部位频次人体热力、组数环形图、时长环比、分部位容量卡）
- **报表页**：周/月统计、周目标达成环、准备度评分、体重趋势、中周期负荷编排、训练日历与个人纪录合并卡（点日期看当日记录）、成就徽章、训练洞察、What-if 模拟
- **动作库**：201 个动作，器械 × 部位双维分类（部位细分如 上/中/下胸、前/中/后束），每个动作配专属 3D 解剖示例图、步骤要领与常见错误
- **饮食模块**：食物库（每 100g 营养参考 + 实物图）、食物选择器、当日营养达成环、Mifflin-St Jeor 个性化饮食规划
- **个性化**：用户画像（性别/年龄/体重/目标/经验）、疲劳模型、伤病禁忌过滤、每日状态（睡眠/酸痛/饮水）
- **深色/浅色主题**：全应用颜色唯一收口于 `ThemeManager` 调色板

## 合规与隐私

- 全部计算在本地完成，无网络请求；历史与设置存于系统 preferences（应用沙箱内）
- 饮食与健康建议固定附免责声明「以上为日常营养参考，非医疗诊断」
- 文件头部注释区分「AI 生成」（脚手架/通用 UI）与「自主业务逻辑」（规则算法）

## 构建与运行

1. 用 DevEco Studio（HarmonyOS NEXT SDK）打开本工程
2. 同步 hvigor 包装器并配置签名
3. Build → 运行到模拟器/真机
4. 单元测试：`hvigorw test -p module=entry`（Upgrade 套件 25 个用例 + 其余套件）

详细说明见 [构建指导.md](构建指导.md) 与 [ARCHITECTURE.md](ARCHITECTURE.md)。

## 目录结构

```
entry/src/main/ets/
├── agent/        # 端侧规则引擎（分析引擎、RuleConfig、rules/ 各规则算法）
├── components/   # 通用 UI 组件（卡片、徽章、进度条等）
├── data/         # 本地数据源与持久化（preferences 存储、动作库、食物库）
├── model/        # 数据模型（训练日志、画像、伤病等）
├── pages/        # 页面（首页/发现/报表/动作库/录入/画像/食物选择）
└── theme/        # 主题中枢（调色板唯一来源）
```
